# Streak Keeper（ルーティン習慣化アプリ）

毎日のルーティンを報告して連続記録を伸ばし、守れなかった日は「罰ゲームルーレット」で自分へのサンクションが決まるiPhone向けWebアプリ（PWA）です。

## 機能
- **はじめる準備**：初回起動時に名前・開始日・毎日のチェックリスト（1行に1つ）を入力。テンプレート（自分で作る／サンプル）から始めることもでき、内容はあとから設定でいつでも変更できます。
- **連続記録（ストリーク）**：その日のルーティンをすべてチェックして「完了を報告」すると+1日。
- **報告しないとリセット**：「未完了を報告」した日、または報告しないまま日付が変わった日は連続記録が0に戻り、罰が1件発生します（1日につき1回）。
- **ホーム画面に日数を表示**：ホーム画面に追加して通知を許可すると、アイコンのバッジに連続日数が表示されます（iOS 16.4以降）。
- **罰ゲームルーレット**：失敗した日ごとに1回回す義務があり、結果は回した瞬間に確定（やり直し不可）。罰は「実行済み」にするまで履歴に残ります。
- **罰は自分で編集可能**：デフォルトで10種類（`sanctions.js`）。冷水シャワー、電話でサボり報告、人前で反省文など「誰でも嫌な罰」が中心で、お金の罰（苦手な人に1,000円、友人に5,000円没収）も混ぜています。
- **データ**：端末内（localStorage）に保存。設定からJSONでバックアップ/復元でき、Googleスプレッドシートにも記録できます（下記）。

## 自分用・他の人用
- 誰でも最初の「はじめる準備」画面で自分のチェックリストを作れます。データは端末ごとに別々なので、同じURLを複数人で使えます。
- テンプレートは `presets.js` に入っています。URLの末尾に `#sample` のように付けて開くと、そのテンプレートが最初から選ばれます。

## スプレッドシート連携
報告（完了／未完了／未報告と各チェック項目の結果）、罰の決定・実行、設定（開始日・チェックリスト・罰の一覧）を Google スプレッドシートに1行ずつ記録できます。複数人で同じシートを使っても「名前」列で区別できます。

スプレッドシートに残した記録からアプリを元に戻せるので、機種変更やブラウザのデータ消去にも対応できます。

1. Google スプレッドシートを新規作成し、メニューの「拡張機能」→「Apps Script」を開く。
2. `gas/Code.gs` の中身を貼り付けて保存。
3. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」、実行ユーザー「自分」、アクセスできるユーザー「全員」でデプロイし、表示されたURL（`https://script.google.com/macros/s/…/exec`）をコピー。
4. アプリの「設定」→「Googleスプレッドシート連携」にURLを貼って保存し、「テスト送信」を押す。「記録」シートに test の行が増えれば完了です。

送れなかった記録は端末に残り、次に通信できたときに自動で再送されます。

### 復元するとき
新しいスマホなどでアプリを開き、最初の画面の「スプレッドシートから復元する」に連携URLと前に使っていた名前を入れて「復元する」を押します。記録・チェックリスト・罰の履歴が元に戻ります。

### 注意
- 連携URLを知っている人は、名前を指定して記録を読み書きできます。URLは使う人以外に共有しないでください。
- `gas/Code.gs` を更新したときは、Apps Script で「デプロイを管理」→ 編集 →「新バージョン」で再デプロイしてください（URLは変わりません）。

## iPhoneで使う
1. https://ken2jap-wq.github.io/streak-keeper/ を開く（GitHub Pages で公開）。
2. iPhoneのSafariで開き、共有ボタン →「ホーム画面に追加」。
3. ホーム画面のアイコンから起動し、ホームの「バッジ表示を有効にする」で通知を許可。

> 注意：Webアプリはバックグラウンドで動けないため、バッジの数字はアプリを開いたときに更新されます。報告せずに日付が変わった場合、次にアプリを開いた時点でリセットと罰が反映されます。

## ローカルで試す
```sh
cd streak-keeper
python3 -m http.server 8000
# http://localhost:8000 を開く
```
